# GridLab

**GridLab** is an open-source Android application designed to help
artists and students reproduce reference images on paper using the grid
drawing technique.

The project is currently in its early development and planning stage.
This README provides a basic introduction and will be expanded as
development progresses.

## Overview

GridLab aims to provide a flexible workspace where the physical paper,
drawing grid, and reference image can be configured independently.

Instead of forcing an image to fit a predefined page or grid, GridLab is
being designed to let users:

-   Choose a standard paper size or define custom dimensions.
-   Configure the drawing grid using rows and columns.
-   Position and scale the reference image independently of the paper
    and grid.
-   Work with square or rectangular grid cells.

The goal is to make the grid drawing process easier to configure while
keeping the relationship between the reference image and the physical
drawing area under the user's control.

## Project Goals

-   Provide a free and open-source drawing-grid tool.
-   Keep the core drawing workflow simple and flexible.
-   Avoid advertisements and subscription-based features.
-   Build a maintainable Android application with a clear architecture.

## Technology

The project is being developed for Android using:

-   **Kotlin**
-   **Jetpack Compose**
-   **Material 3**

The application architecture and additional technologies will be
documented as implementation progresses.

## Project Status

GridLab is currently under active planning and early development.
Features and implementation details may change as the project evolves.
